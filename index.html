Petunjuk Penggunaan

Buat laporan kinerja harian Anda dengan mudah dan cepat. Masukkan API Key Google Gemini Anda dan gunakan tombol "Isi Data Contoh" untuk uji coba cepat.

  • 1 Masukkan Google Gemini API Key pada kolom di sidebar kiri.
  • 2 Klik tombol "Isi Data Contoh" atau lengkapi formulir manual.
  • 3 AI (Gemini) akan menyusun narasi akademik profesional secara otomatis berdasarkan input Anda.
  • 4 Klik "Generate Laporan Ekin" dan Export ke PDF Full Color.
